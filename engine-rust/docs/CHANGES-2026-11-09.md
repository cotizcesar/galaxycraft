# 2026-11-09 — Collections unit skins and selection state

## Intro captures

`--shot-screen intro` used to write a black frame: the establishing-caption
path reset the movie clock to zero before the decoder opened the file, so
the requested 5 s / 25 s seek never reached ffmpeg.  The capture now marks
the title movies as caption-free and the decoder receives the requested
time; `intro` shows the `Blizzard Entertainment Presents` card and
`intro-title` a title scene with its subtitle.

## What changed

- The Collections screen now selects the cell under the click.  The blue
  frame used to stay on the first item of every section because the cell
  table carried a hardcoded selection flag; it now follows
  `collection_sel`, and the cached plate is rebuilt when the selection or
  the equipped set changes.
- `EQUIP` applies the Unit & Structure collection:
  - **Default** (cell 3) restores the base HD art.
  - **Carbot** (cell 4) reads the shipped `anim/carbot/main_NNN.anim`
    containers for every unit.
- The equipped unit set shows a green dot on its cell, and the preview
  column reads `EQUIPPED` in place of the grey `EQUIP` label.
- The setting is stored in the profile (`game_unit_skin`, key/value codec
  in `menu.rs`), so it survives a restart like the other options.
- Console skins are now applied: cells 0-2 equip Default/Silver/Gold,
  persisted as `game_console_skin`, and the client loads the race art or the
  shipped `game/consoles/krc_silver` / `krc_gold` plates.
- Announcers are now applied: cells 5-10 equip Default/Um/Jeon/Kim/
  UmJeonKim/HeyJini, persisted as `game_announcer`; advisor lines and the
  mission-start line come from the selected shipped voice set.
- Carbot now changes the HUD as well as the unit art: command icons, HUD
  resource icons and wireframes load from `carbot/unit/...` and
  `carbot/game/icons.dds.grp`.  Portraits keep their base art because the
  shipped Carbot collection has no portrait sheet.
- The hidden `ShowTurnRate` option key (registered by the retail config
  routine at `0x006e2653`) now draws `TURN <n>` for the first selected
  flingy, using its `flingy.dat` turn rate; `--show-turn-rate` forces it for
  captures.  `ShowFPS` is drawn in the same in-game overlay path (it was
  previously reached only from the menu draw path).
- Sound tab "Sound Plays While In Background" is now consumed: losing window
  focus pauses the mixer when the checkbox is off and resumes at the same
  position when focus returns.  `AudioMessage::Background` and the mixer test
  pin the behavior.
- "Building Sounds" now gates voices emitted by structures, and "Original
  1998 Campaign" prefers an optional `voices/sd/...` classic bank with a
  fallback to the current one.  The local 1.23.10 install has no classic SD
  files, so the fallback is what runs here.
- Acid Spores now use the recovered nine-slot timer stack: `FUN_005dc360`
  fills the first free slot (or refreshes the stack closest to expiring when
  all nine are busy) with `0x96` ticks, and `FUN_005dc940` removes one stack
  per expiry.  Before this they never expired.  Corrosive Acid keeps its
  single-target 25 damage but spores every non-building unit in the 128x128 px
  box that `FUN_005dc1c0`/`FUN_006c1ee0` scan (half-extent `0x40`), skipping
  units of the attacker's own player, loaded units and cloaked units the
  attacker cannot see.  Restoration clears
  the stacks and active spores reveal cloaking until they expire.  The timer
  updates every eighth logical tick, so `0x96` updates last ~50 s at 24 Hz.
  `FUN_005b6900`'s speed clamp was also wired into `speed_of` (Stim +50% with
  the `0x355` floor, Ensnare halves, hero types `0x46/0x50/0x58` pinned at
  `0x6ab`).
- Unit box accessors `0x5b6a60/80/90/a0`: `Box16::extents`/`rect_at` now
  expose the four directional `units.dat` half-extents.  Path obstacles and
  the build/land blocker rectangles use `[x-left, y-top, x+right, y+bottom]`
  instead of a symmetric maximum, so asymmetric boxes (Wraith, Science
  Vessel, Bunker) no longer over-block one side.
- Defensive Matrix now keeps the recovered duration timer at `CUnit+0x114`:
  `FUN_005d2840` sets the pool to 64000 and the timer to `0xa8`, and
  `FUN_005cf290` decrements it every eighth logical tick.  On expiry the pool
  is cleared and a break cue is emitted, exactly like a pool-breaking hit.
  `MatrixCue { unit, x, y, absorbed, broke }` records every absorbed hit;
  `Status::apply_matrix`/`absorb_matrix`/`tick_matrix` implement the state
  machine, and the cues are cleared at the start of every tick.
- Restoration targeting now has the recovered `FUN_005c7460` predicate
  (`World::restoration_worthwhile`: same owner, at least 60 whole HP+shields,
  at least one removable status), and both Restoration paths clear Parasite
  as well as the existing statuses and Acid Spores.  The predicate is
  available to AI target selection but no AI routine calls it yet.
- The `CUnit` status timers now follow `FUN_005cf290`'s eighth-tick
  cadence: Ensnare/Plague/Irradiate 75 updates, Lockdown/Stasis 131,
  Maelstrom 22.  Irradiate deals `(250 << 8) / 75 = 853` per update; Plague
  deals `(300 << 8) / 0x4c = 1010` and skips the tick that would reach the
  current HP.  Stasis now expires (its timer was previously decremented and
  then frozen by the early return) and the status counter `+0x122` is the
  shared 8-tick cadence.  `+0x54..0x57`, `+0xe3` and `+0x110` are documented
  as order/AI/visual retry counters, not status effects.
- Ensnare, Plague, Stasis Field and Maelstrom now apply the recovered hit-
  type filters: burrowed units are skipped by all four; Stasis and Maelstrom
  skip buildings; Maelstrom also requires an organic target.
- Irradiate now follows hit type 9: any non-building unit can carry the aura,
  but only biological units within 32 px of the source's collision box take
  the 853/256 damage; a mechanical source is immune while still splashing,
  burrowed units only take the direct hit, and larvae/eggs/buildings are
  immune.
- `CUnit+0x110` is mapped to the temporary-unit expiry (`expires_at`);
  `spawn_temporary` keeps the earlier of two lifetimes like `FUN_005b6810`;
  `temporary_units_expire_on_the_recovered_lifetime_timer` pins the expiry.
- A fully absorbed Defensive Matrix hit no longer chips 0.5 HP or shields
  through the post-size floor; `resolve_damage_status` returns zero damage
  when the matrix consumes the whole hit.
- The replay state hash now covers future-deciding fields that were omitted:
  `energy_frac`, `larva_timer`, `expires_at`, `order_carry`, `order_row`,
  animation state, path/rally/production/cargo/addon state, damage-source,
  invincibility and temp-unit/spider-mine timers.  A divergence test pins
  energy fraction, larva timer, expiry, carry and path queue.
- Ground obstacles no longer include flyers; the asymmetric obstacle test
  now uses a Barracks (`left 48, right 56, top 40, bottom 32`).
- Ensnare now affects air units while skipping buildings, burrowed units,
  loaded units and the caster; the previous `!is_air_unit` filter was
  inverted.
- Carrier Attack row 20 now has its recovered 60-tick launch phase before
  the first interceptor fires (`CUnit+0x55 = 0x3c`).
- Larva production uses `37 * 8 = 296` ticks (`0x25` status updates) and the
  duplicate Hatchery-only decrement was removed.
- Order queueing now uses `orders.dat` field 7 (`can_be_queued`) for
  replace-vs-queue and `highlight != -1` only for the eight-slot count.
- `Scenario::parse` now accepts the Remastered `STRx` table (u32 count and
  offsets) when present, falling back to the classic 16-bit `STR`; ladder
  maps that ship only `STRx` resolve their title, description and trigger
  text.
- Loaded cargo now dies with its transport/Bunker: the cargo loop no longer
  skips units hidden with `alive = false`, and clears `in_transport`, HP and
  the cargo list. The reconstruction test asserts HP 0 and unlink.
- Loading now rejects enemy owners, unfinished/self transports and building
  cargo; `transports_reject_enemy_and_unfinished_carriers` pins the gates.
- Add-on construction now enforces the same requirements as the command
  card (Comsat needs Academy, Nuclear Silo needs attached Covert Ops);
  `addons_require_academy_and_covert_ops` pins the gate.
- Research and upgrade cancellation now refund the full current-level price
  (`0x5d9f80`/`0x5da010`) and clear `build_remaining`/`build_total`;
  `cancel_research_and_upgrade_refunds_the_full_price`.
- Upgrade research costs and times now use the player's current level
  (`0x5da5d0`), so the first level costs the base 100/100 and 4000 ticks;
  `upgrade_costs_and_times_use_the_current_level` pins both table and sim.
- Region-neighbour and region-centre lookups `0x75d6b0`/`0x75d660` are now
  `RegionMap::neighbours_of` and `RegionMap::region_centre_px`; the A* uses
  the neighbour lookup and the test pins reciprocal adjacency and the
  `centre_cell * 8` pixel conversion.
- Door unit types `0xcd..0xd0` (`0x5b5b00`) are excluded from automatic
  targeting and ground-unit separation.
- Phase 2 triage: the matrix cues, Restoration predicate, region lookups and
  door predicate are the new ports; `0x655140` calls into a non-decompilable
  body and `0x984770` is a bounds assertion whose safe-access behaviour is
  already present.  See `IMPLEMENTATION-PHASES.md`.

## Console skins

The three Collections console cells now equip the shipped KRC sets instead
of only previewing them:

| Cell | Skin | CASC directory |
|---|---|---|
| 0 | Default | `game/consoles/<race>` |
| 1 | Silver | `game/consoles/krc_silver` |
| 2 | Gold | `game/consoles/krc_gold` |

`game_console_skin` is stored in the profile with the other settings, so the
choice survives a restart.  The KRC sheets carry large transparent margins
(2505x822 left, 1108x710 centre, 2505x750 right); `ConsoleArt::load` crops the
dark margins, which brings the plates back to the native height of the race
console.  The command-well crop and the centre info-panel rectangle are
skin-specific fractions measured on the KRC art, and the race-independent
files are materialised by the retail cache (`KRC_CONSOLE_FILES`).

`--console-skin default|silver|gold` forces a set for headless captures.

or `gamestart`.  The cache materialises all 485 shipped announcer WAVs under
