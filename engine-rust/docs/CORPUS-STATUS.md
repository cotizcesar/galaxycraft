Generated by `python3 scripts/corpus_audit.py --markdown`.  The audit checks
that every retail function sits in exactly one bucket (translated / thunk /
decompile_failed / one triage category), that `triage.tsv` covers exactly the
uncited rows and that `skiplist.tsv` has no duplicate, unknown or already
translated rows.  Result: **the books balance**.

(why an uncited row is not queued) and `skiplist.tsv` (assigned to a wave,
not translated).  Skip reasons per row were not kept: the staging files are
deleted after each merge.

Note on wiring: "called from non-test code" counts any reference outside a
test module, including calls from other wave helpers, so it is an upper
bound on what the engine really uses.
